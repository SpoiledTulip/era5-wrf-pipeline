# 阶段 -1：需求澄清与实验计划书

## 使用规则

分四批问，每批 3–4 个问题；用户确认当前批后再进入下一批。用户答不上来时给选项、推荐默认值和理由。未形成并确认计划书，禁止下载和提交作业。

## 第 1 批：意图与用途

1. 这次模拟什么对象？A 某台风个例；B 某次暴雨/强对流；C 梅雨/海雾过程；D 其他（请给时间和地点）。
2. 为什么做、给谁看？A 自己诊断（推荐）；B 组会；C 课程/气创赛；D 论文/投稿；E 老师要求对比。
3. 有没有参考个例？A 继承白海豚 v2 双域；B 继承巴威单域；C 从零按区域和尺度设计。

默认：若未指定，按“自己诊断 + 白海豚 v2 配置作起点”，但仍需用户确认。

## 第 2 批：时空与配置

1. 起报时间（UTC）和积分：24/48/72/120 h 中选，或给具体值。
2. 区域：A 给中心经纬度和范围；B 照参考个例；C 由助手按系统尺度定并解释。
3. 嵌套：A 单域 9–15 km；B 双域 15+5 km（推荐）；C 三域 15+5+1/3 km。
4. 物理方案：默认继承 `namelist_dolphinv2.input` 的 WSM6 + KF + YSU + Noah + RRTMG；若网格小于 5 km，必须重新讨论积云方案。

## 第 3 批：图形需求

1. 图型可多选：形势场、降水、时间序列、垂直剖面、误差评分、台风路径。
2. 每类图说明要素、层次、时次和范围；答不清时推荐：SLP+10 m 风关键时次、500 hPa 位势高度+风、累积降水。
3. 语言：`en`（默认，兼容投稿）或 `zh`。
4. 规格：`draft` 150 dpi PNG（默认）、`presentation` 200 dpi、`publication` 300 dpi PNG+PDF；拼图单张/多时次/多要素。

## 第 4 批：交付与验收

1. 是否只要模拟结果，还是要明确的 ERA5/观测对比？
2. 验收：A 跑通并能看图（默认）；B 可放组会；C 需评分/误差和方法说明。
3. 交付：PNG；若 publication 再加 PDF。


计划书确认后，把原文保存为案例 `plan.md`，再进入阶段 0。
